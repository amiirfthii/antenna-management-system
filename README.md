# Antenna Management System

A web-based antenna management and repair tracking system developed as a portfolio project.

## Features

- Antenna inventory management
- Repair and maintenance tracking
- User authentication
- Role-based permissions
- Dashboard and reporting
- Excel import and export
- Serial number management
- Jalali date support
- REST API endpoints
- Database migrations

## Technologies

- Python
- FastAPI
- SQLAlchemy
- Alembic
- SQLite / MySQL
- HTML / CSS
- TypeScript
- Git

## Project Structure

backend/
- app/
- alembic/
- tests/

frontend/
- src/

## Setup

1. Create a Python virtual environment.
2. Install dependencies from `backend/requirements.txt`.
3. Copy `backend/.env.example` to `backend/.env`.
4. Configure the required environment variables.
5. Start the backend application.

## Security

This repository is a sanitized portfolio version of the original project.

Real user data, credentials, database files, organization-specific information, and private documents have been removed.
